## Acceptance rules

A scenario passes only when:
1. Actual observed behavior matches the expected result.
2. Any required state change is verified, not inferred from a success message alone.
3. Evidence filename, environment, and build reference are recorded where available.
4. No confidential data or secrets appear in evidence.

Use Pass, Fail, Blocked, or Not run only according to actual execution. Automated tests do not count as browser UAT.
